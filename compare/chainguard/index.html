Minimal vs Chainguard

Chainguard largely created this category, and Minimal is built on Wolfi and apko — their open-source work. This is not a claim to replace them. It is a measured answer to one specific question: if you want hardened images without a paid tier, what do you actually give up?

The honest framing

Chainguard's free tier publishes a limited set of images; the full catalog is commercial. When this scan ran on 2026-11-01, 20 of Minimal's images had a free, publicly pullable Chainguard equivalent. Of those, 16 were exact or same-major/minor version pairs and were scored; 4 mismatched or unknown pairs were excluded. This table is narrow by construction, and that is the most important caveat on the page. Missing images are never scored as wins.

When Chainguard is the right answer

If you need thousands of images, FedRAMP or STIG artifacts, SLSA Build L3, a vendor SLA, or CVE remediation someone is contractually obliged to deliver — buy the product. Minimal offers none of that, and pretending otherwise would be the kind of claim this project has already had to retract once.

Minimal fits when you want a catalog small enough to read end to end, every recipe in one MIT-licensed repo, at zero cost and with no account.

How these numbers were produced

  • Scanner: Grype 0.109.1, vulnerability DB schema v6.1.10, built 2026-11-01T06:20:12Z.
  • DB checksum: https://grype.anchore.io/databases/v6/vulnerability-db_v6.1.10_2026-11-01T00:24:34Z_1793514012.tar.zst?checksum=sha256%3Ad0e1af9e6491440e1a671d0a0aafc32c5c7cb5cda787dcec3482799ef298f31c
  • Platform: linux/amd64. Scan date: 2026-11-01.
  • Production latest tags were resolved to immutable digests before scanning, so the run is repeatable.
  • Every image was scanned with the same Grype binary and the same frozen database.
  • Raw Grype findings. No vendor VEX suppression was applied to anyone, including us.
  • Only publicly pullable images were scanned. No paid or private registry credentials were used.
  • Only exact or same-major/minor upstream version pairs are scored. Mismatched and unknown versions are excluded.

The full 600-row dataset, including the resolved reference and digest for every provider/image pair, is here: cve-comparison-2026-11-01.csv. The scored-pair inputs and version classifications are here: cve-comparison-pairs-2026-11-01.csv. Every figure on this page is derived from those files.

What this does not prove

Exact versions can still bundle different feature sets, and same-major/minor pairs can use different patch releases, so an individual outlier still needs inspection before it is treated as a product-level claim. A scanner reports known findings visible to one database snapshot; a low count is not proof that an image is free of vulnerabilities. An image a vendor does not publish is counted as not available — never as zero.
