amazon-cloudwatch-agent

Amazon CloudWatch Agent ships host and container metrics, logs and traces to CloudWatch, incl. Container Insights. Upstream /opt/aws layout, shell-less.

Pull this image

docker pull ghcr.io/rtvkiz/minimal-amazon-cloudwatch-agent:latest

No shell in this image, so docker exec … sh won't work. To debug, run the -dev variant or attach an ephemeral container with kubectl debug. How to debug a container with no shell 

docker pull ghcr.io/rtvkiz/minimal-amazon-cloudwatch-agent:latest-dev

The -dev variant adds a shell, package manager and build toolchain. For CI and debugging — not production.

  --certificate-oidc-issuer='https://token.actions.githubusercontent.com' \
  ghcr.io/rtvkiz/minimal-amazon-cloudwatch-agent:latest
