argo-cd-repo-server

Argo CD repo-server rendering manifests from git with bundled Helm and Kustomize. Shell-less despite the tooling, signed, rebuilt daily against CVE fixes.

Pull this image

docker pull ghcr.io/rtvkiz/minimal-argo-cd-repo-server:latest

No shell in this image, so docker exec … sh won't work. To debug, run the -dev variant or attach an ephemeral container with kubectl debug. How to debug a container with no shell 

docker pull ghcr.io/rtvkiz/minimal-argo-cd-repo-server:latest-dev

The -dev variant adds a shell, package manager and build toolchain. For CI and debugging — not production.
