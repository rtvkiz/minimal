What "zero" means here

Grype matched no known vulnerability against any package in the production image, using the vulnerability database current at scan time. That is a statement about known, published CVEs on that day, not a guarantee that the software has no bugs. A new advisory can add a CVE to any image tomorrow; the daily rebuild then picks up the fix once the package is patched, and this page follows the scan. Another scanner can report a different number for the same image, and both can be right: see why two scanners disagree and why your scanner reports zero CVEs.

Every image's current findings are on its Advisories tab, and how to read them is in reading scan results. All 200 images are in the full directory.
